# Test Project

Creating my own stuff - a personal web development project.

## Overview

This repository contains a web application with authentication features, built with HTML, CSS, and JavaScript, along with some Java backend components.

## Project Structure

### Frontend Pages
- **index.html** - Landing/home page
- **home.html** - Main home page with styling and interactivity
- **login.html** - User login page
- **SignUp.html** - User registration page
- **load_page.html** - Loading screen page

### Styling
- **index.css** - Styles for landing page
- **home.css** - Styles for home page
- **login.css** - Styles for login page
- **SignUp.css** - Styles for sign-up page
- **loading.css** - Styles for loading animations

### JavaScript
- **home.js** - Home page functionality
- **login.js** - Login page logic
- **SignUp.js** - Sign-up form handling
- **loading.js** - Loading screen animations
- **Signin.javascript** - Sign-in related functionality

### Backend
- **backend.java** - Java backend implementation
- **backEnd.class** - Compiled Java class file

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java
- **Version Control:** Git

## Features

- User authentication (login/sign-up)
- Loading animations
- Responsive styling
- Backend Java integration

## Getting Started

1. Clone the repository
2. Open `index.html` or `home.html` in your browser
3. Navigate through the authentication pages (login/sign-up)
